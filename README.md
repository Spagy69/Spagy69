## Featured project

**[ESP32-C3 Air Quality Monitor](https://github.com/Spagy69/ESP32-C3-Air-Quality-Monitor)**

Battery-powered air quality monitor (CO₂, temperature, humidity, pressure) built on Seeed XIAO ESP32-C3, running ESPHome and integrated into Home Assistant. Features deep sleep for battery operation, a local CO₂ alarm, and a custom 3D-printed enclosure.

Everything in the documentation is backed by real measured data, including sensor calibration, power management and the hardware issues encountered during development.
